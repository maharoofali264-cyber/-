# -
My colour book 
Create a beautiful, child-friendly Digital Coloring Book Web App for children aged 4–10 years.

Main Requirements

- The app should be simple enough for a 4-year-old to use.
- Attractive, colorful, playful design.
- Mobile-first design because children will mainly use it on a phone/tablet.
- No login or complicated setup.
- Large buttons and easy navigation.
- The coloring pages should contain black-and-white line drawings with clear, thick outlines.
- Children should be able to color the pictures by tapping/clicking areas.
- Include a color palette with many bright colors.
- Add an eraser, undo, redo, clear, and save/download options.
- Add Previous / Next buttons to move between pages.
- Show page number, e.g. Page 1 of 20.

Age Categories

Divide the book into:

1. Ages 4–5 – very simple pictures with large areas.
2. Ages 6–7 – medium-complexity pictures.
3. Ages 8–10 – more detailed pictures.

User Interface

Home screen:

- Title: My Coloring Book
- Large Start Coloring button
- Age category buttons: 4–5 | 6–7 | 8–10
- A simple gallery showing available coloring pages.

Coloring screen:

- Drawing in the center.
- Color palette at the bottom.
- Undo
- Redo
- Eraser
- Clear
- Save
- Previous
- Next

Important

Make the coloring experience smooth and fun for children. Avoid small buttons, complicated menus, advertisements, or unnecessary text.

Use HTML, CSS and JavaScript (or React if appropriate). Make the project fully functional and responsive.

Also structure the code so that I can easily add new coloring pages later without rewriting the entire application.

First create the working app with sample coloring pages and make sure all buttons and coloring functions work correctly.
